# 坦克大战 · Battle City

一个用纯 HTML / CSS / JavaScript（Canvas）实现的经典《坦克大战》网页游戏，单文件即可运行，无需任何依赖或构建工具。

## 🎮 玩法

- 控制你的坦克，**消灭所有敌军坦克**，同时**保护基地（鹰旗）不被摧毁**。
- 每关敌军数量会逐渐增多，关卡地图轮换。

## ⌨️ 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W A S D` 或 `方向键` |
| 射击 | `空格` 或 `J` |
| 暂停 / 继续 | `P` |
| 开始 / 重开 | `回车` 或点击按钮 |

## ✨ 特性

- 3 种敌军坦克：普通、快速、重型（需 2 次命中）
- 可破坏的砖墙、不可破坏的钢墙、基地
- 3 张轮换关卡地图
- 道具掉落：护盾、火力升级、额外生命
- 得分、最高分（本地存储）、生命、剩余敌军 HUD
- 粒子爆炸特效、Web Audio 合成音效
- 敌军出生保护动画、玩家出生护盾

## 🚀 运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
# 使用 Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```
